## Decisiones de implementación (F0, 2026-10-05)

| ID    | Decisión                                                                                                           | Motivo                                                                                                                       |
| ----- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| D-018 | TypeScript fijado en `~5.9`                                                                                        | TypeScript 7 (versión nativa) no expone la API de JS que usan `openapi-typescript` y `vue-tsc`; falla la generación de tipos |
| D-019 | `NUXT_PUBLIC_API_BASE_URL` se fija **al construir**                                                                | Build estático (`nuxt generate`): no hay servidor que inyecte variables en tiempo de ejecución. Un build por ambiente        |
| D-020 | Iconos (Lucide) incluidos en el bundle, sin proveedor remoto                                                       | SPA sin servidor; evita depender de la API de Iconify y simplifica la CSP                                                    |
| D-021 | Pruebas del cliente HTTP en entorno Node, no happy-dom                                                             | happy-dom aplica CORS y descarta `Authorization`; los navegadores reales sí lo envían con preflight                          |
| D-022 | Regla de lint: una feature no importa a otra (`no-restricted-imports`) y `vue/no-v-html` como error                | Aplica D-P17 y la política de seguridad de D-P03                                                                             |
| D-023 | Documentación del proyecto versionada en el repo (`docs/`) y copiada a la carpeta del proyecto al cerrar cada fase | La documentación viaja con el código y se revisa en los PR                                                                   |
