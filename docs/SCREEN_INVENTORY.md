# SCREEN_INVENTORY

**Última actualización:** 2026-10-05 · Fuente: `app/pages/**` y los componentes que componen. Rutas y parámetros en ROUTE_MAP.md; permisos por acción en AUTHORIZATION_MATRIX.md.

Todas las pantallas con datos tienen estados de carga (skeleton), vacío, error con "Reintentar" y referencia de soporte (`QueryState`, `ProblemAlert`), y toasts de éxito o error tras cada acción. Todas pasan axe sin violaciones WCAG 2.1 A/AA (tests/e2e/a11y.spec.ts).

## Acceso y cuenta

| Pantalla               | Ruta                    | Componentes                         | Qué hace                                                                                                                                                                        | E2E     |
| ---------------------- | ----------------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| Iniciar sesión         | `/login`                | página                              | Email y contraseña; credenciales inválidas, cuenta de cliente rechazada, otros errores con `ProblemAlert` (un 429 muestra la espera de `Retry-After`) y vuelta a la ruta pedida | auth    |
